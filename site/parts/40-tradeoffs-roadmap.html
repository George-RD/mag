What you gain. What you accept.

Local-first removes one trade-off and adds another. The useful choice is the honest one.

MAG is a good fit when…

  • You switch between coding agents and want context to follow.
  • You work with client or private data that should stay on the machine.
  • You want a memory store you can inspect, export and keep.
  • You prefer an open local tool over another hosted account.

Choose something else when…

  • You need team-wide cloud sync now.
  • You need the app itself to encrypt its data.
  • You want a browser service with no local model download or setup.
  • You expect memory to decide what matters with no guidance or cleanup.

Current limits: MAG is a 0.1.x project. APIs and setup may still move. The local search model takes about 32 MB on disk and roughly 180 MB peak memory when loaded. Windows builds exist, but Windows has had less testing than macOS and Linux. The SQLite database is plaintext.

Built in public. No invented dates.
